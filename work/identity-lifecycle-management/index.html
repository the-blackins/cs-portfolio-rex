02 / IAM HOME LAB / ACTIVE DIRECTORY

Identity changes, handled with intention.

I designed and implemented a Joiner-Mover-Leaver identity lifecycle lab in Windows Active Directory. This is Identity and Access Management (IAM) work in a simulated setting: across four departments, the workflow covered provisioning, role changes, and offboarding, using security groups and PowerShell for recurring administration tasks.

00 / OVERVIEW

Accounts change. Access should change with them.

The lab addressed account and access changes across the employee lifecycle: assigning access to joiners, adjusting it when roles change, and deprovisioning accounts on exit.

It was a simulated environment across four departments. The newly supplied presentation shows HR, ICT, Sales, and SOC organizational units; it does not provide a user count.

01 / PROCESS SUMMARY

Joiner → Mover → Leaver

The selectable stages below summarize the process described in the project account. This illustration is conceptual. The separate recording below documents one joiner account-creation step.

Accounts were provisioned and access was assigned through Active Directory security groups.

What each stage covered

  • Joiner: Account provisioning and role-associated access through AD security groups.
  • Mover: Group membership changes for role transfers, followed by access review for privilege creep.
  • Leaver: PowerShell-supported offboarding and same-day deprovisioning within the simulated process.
  • Access review: A described process to identify and address access retained after role changes.
02 / ACCESS MODEL & AUTOMATION

Groups before individual permissions

I used AD security groups to represent role-based access instead of assigning permissions directly to each user. I developed PowerShell scripts for account provisioning, group membership changes, and offboarding, and documented the process with role matrices and evidence.

Those scripts and matrices are described in my résumé but are not included in the supplied portfolio materials. No invented code sample or output is shown here.
